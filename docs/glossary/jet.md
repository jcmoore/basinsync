# Jet

A server-driven *Reservoir*[~][reservoir] in *KernelSpace*[~][kernelspace]
that ingests *DifferentialEvents*[~][differential-event]
to arrange in *Flow*[~][flow] *Timelines*[~][timeline], as a *Basin*[~][basin]
ingests *CommitMarkers*[~][commit-marker] to arrange in *Flow*[~][flow]
*Epilogues*[~][epilogue].
