# Heap reservation

A durable staging *retainer*[~][retainer] edge from a *Flow's*[~][flow] next
*Viewpoint*[~][viewpoint] to a *node*[~][node], established before upload.
It stages data in *UserSpace's*[~][userspace] *Heap*[~][heap].

It fixes the reserved content length, *context*[~][context], and child-id set.
