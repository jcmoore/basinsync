# Basin

A server-driven *Reservoir*[~][reservoir] in a *Datashed's*[~][datashed]
*KernelSpace*[~][kernelspace] that ingests
*CommitMarkers*[~][commit-marker] to arrange in *Flow*[~][flow]
*Epilogues*[~][epilogue]. Its *Timeline*[~][timeline] records their state changes;
API responses identify that log as `timelines.basin`.
